# MAM-mac

A one-click installer for the tooling that gets Monsters and Memories running "natively" on a Mac.

Created 2026-10-05 by command-control at the owner's request. Nothing is built yet.

## The objective (the owner's words, 2026-10-05)

> i just read that monsters and memories has a mac launcher option now: https://account.monstersandmemories.com/launcher but it requires wine and proton. start a new repo called MAM-mac, the objective of this repo is to be the one click installer for the tooling to get Monsters and memories running "natively" on mac

## What that means

- Monsters and Memories now offers a Mac launcher option at https://account.monstersandmemories.com/launcher.
- That option needs Wine and Proton set up on the Mac first.
- This repo is the one step that installs and configures that tooling, so a Mac user runs one thing and can then play.

What the launcher needs exactly (versions, how it is started, where the game installs) has not been checked yet; that is the first job in this repo.
